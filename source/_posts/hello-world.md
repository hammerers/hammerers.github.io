欢迎来到我的个人博客！本博客基于 **Hexo** 与 **NexT (Gemini Scheme)** 搭建，已开启现代化毛玻璃卡片与悬浮动效。

<!-- more -->

## 特性概览

> 💡 **小贴士**：所有文章支持 Markdown 语法、LaTeX 数学公式、代码高亮与站内即时检索。

### 1. 代码高亮测试

```javascript
// 一段简单的 JavaScript 示例
function greet(name) {
    const greeting = `Hello, ${name}! Welcome to my blog.`;
    console.log(greeting);
    return greeting;
}

greet('World');
```

### 2. 常用操作指令

- **新建文章**：`npx hexo new "文章标题"`
- **本地预览**：`npx hexo s`
- **生成静态页**：`npx hexo clean && npx hexo g`
